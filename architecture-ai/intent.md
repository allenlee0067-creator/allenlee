# Arch AI Drawing Kit — Intent

> 2026-11-09 사용자 인터뷰 답변을 기준으로 정리. 결정이 바뀌면 이 문서를 먼저 고친다.

## 목적
건축 설계자가 **치수와 프로그램만 입력해서 발표 보드 수준의 도면 이미지**를 빠르게 얻게 한다.
도면 5종을 한 도구에서 만들고, 그 도면을 AI 렌더의 **형태 기준**으로 써서 레퍼런스 품질로 마감한다.

| 용도 | 의미 |
|---|---|
| 내부 설계 검토 | 맴맴곳곳 디자인랩이 매스·평면·단면 대안을 빠르게 비교 |
| 외부 공개 도구 | 다른 건축 실무자가 웹에서 바로 쓰는 공개 서비스 |

## 사용자
- **1순위: 건축 실무자** (설계사무소 건축가·디자이너)
  - 도면 용어(FFL, 포셰, 그리드 축, 단면선)를 설명 없이 쓴다.
  - 실무 수치(층고, 슬래브 두께, 벽체 구성)를 그대로 입력할 수 있어야 한다.
- 화면 언어: **한국어만**

## 품질 기준 (레퍼런스)
| 순서 | 탭 | 맞춰야 할 수준 |
|---|---|---|
| **1** | 02 평면도 | 공모전 배치 평면: 검은 포셰 벽, 회색조 조경(나무·포장), 그림자, 가구, 실 태그 |
| 2 | 04 단면투시 | 공모전 단면투시: 진갈색 포셰, 붉은 동선, 아트리움, 군중, 하늘·도시 배경 |

| 4 | 03 입면도 · 05 디테일 | 벽돌 한 장 단위 질감 입면 + 단면 스트립 / 흑백 선화 상세 단면 |

네 탭 모두 우선이지만, **평면도를 가장 먼저** 레퍼런스 품질까지 끌어올린다.

## 핵심 결정
1. **형태는 코드, 마감은 AI.**
   코드로 그린 SVG는 구도·선 언어·정확한 치수까지 책임진다. 손으로 마감한 보드 수준의 질감과 밀도는 코드로 닿지 않으므로, 이미지 AI가 마지막 단계를 맡는다.
2. **AI 서비스는 OpenAI가 기본.**
   `gpt-image` 계열의 `images/edits`를 쓴다. Gemini는 대안으로 남겨 둔다.
3. **AI 비용은 사용자 본인 키로.**
   사용자가 자기 OpenAI 키를 넣고 비용도 본인이 낸다. 그래서 서버, 로그인, 결제, 사용량 제한이 필요 없다.
4. **키는 사용자 브라우저에만.**
   서버를 거치지 않고 OpenAI로만 전송된다. 브라우저 저장은 선택 사항이다.
5. **AI에는 항상 두 가지를 같이 보낸다.**
   ① 현재 도면 PNG(형태 고정) ② 사용자가 올린 레퍼런스 이미지(스타일). 레퍼런스가 없으면 탭별 기본 스타일 문장을 쓴다.
6. **형태를 바꾸는 AI 결과는 실패로 본다.**
   지시문은 층·창·벽 위치를 바꾸지 말 것, 가짜 글자를 만들지 말 것을 항상 포함한다.
7. **도면은 결정론적이다.**
   같은 입력이면 같은 도면이 나온다(시드 고정 난수). 변주는 '수목 변주', '재질 변주' 숫자로만 바꾼다.

## 공개 위치
- **운영:** `www.mmggdesignlab.com/architecture-ai` — `mmgg-website` 저장소의 `architecture-ai/` 폴더. 사이트 왼쪽 메뉴 맨 아래 'AI 도면'.
- **개발용 사본:** `mmggdesignlab.vercel.app/architecture-ai/` — `allenlee` 저장소.
- 두 사본은 같은 파일 3개(`index.html`, `studio.js`, `render-ai.js`)다. 고치면 두 저장소에 같이 반영한다.
- 실제 도메인은 끝에 `/`가 붙지 않는 주소(`trailingSlash: false`)라서 스크립트 경로는 반드시 `/architecture-ai/…` 절대 경로로 쓴다.

## 구조
| 파일 | 역할 |
|---|---|
| `index.html` | UI, 입력 폼, 기본 도면 함수, 프롬프트 조합, PNG/SVG 저장 |
| `studio.js` | 발표용 도면 엔진. 다섯 렌더러를 교체 (`drawMass`, `drawPlan`, `drawElev`, `drawSection`, `drawDetail`) |
| `render-ai.js` | AI 렌더 패널. OpenAI `images/edits` / Gemini `generateContent` 호출 |

## 하지 않는 것
- 실시공용 도면, 법규·구조 검토 (평면 배치는 면적 비율 개략안, U값은 참고치)
- 서버, 로그인, 결제, 사용자 데이터 저장 (본인 키 방식이라 필요 없음)
- 영어 등 다국어 UI
- 특정 실존 건축물이나 사무소 작품의 복제

## 성공 판단
레퍼런스 이미지 옆에 AI 렌더 결과를 놓았을 때, **형태는 입력값 그대로이고 그래픽 톤은 레퍼런스와 구분하기 어려우면** 성공이다.
외부 공개 기준으로는 **처음 온 건축 실무자가 설명 없이 키를 넣고 첫 렌더까지 5분 안에** 도달하면 성공이다.
