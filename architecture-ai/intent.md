# Arch AI Drawing Kit — Intent

## 목적
건축 설계자가 **치수와 프로그램만 입력해서 발표 보드 수준의 도면 이미지**를 빠르게 얻게 한다.
도면 5종을 같은 도구 안에서 만들고, 그 도면을 AI 렌더의 **형태 기준**으로 써서 레퍼런스 품질로 마감한다.

- 대상: 맴맴곳곳 디자인랩 내부 설계 작업, 상담·제안용 이미지 제작
- 위치: `architecture-ai/` (정적 페이지, 빌드 없음) · 메인 사이트 상단 메뉴 `AI Drawing Kit`

## 품질 기준 (레퍼런스)
| 탭 | 맞춰야 할 수준 |
|---|---|
| 01 다이어그램 | BIG(big.dk) 다이어그램: 흰 아이소 매스, 강조색 조작 화살표, 녹화, 작은 사람 |
| 02 평면도 | 공모전 배치 평면: 검은 포셰 벽, 회색조 조경(나무·포장), 그림자, 가구, 실 태그 |
| 03 입면도 | 벽돌 한 장 단위 질감 입면 + 오른쪽 선화 단면 스트립(레벨 표기) |
| 04 단면투시 | 공모전 단면투시: 진갈색 포셰, 붉은 동선, 아트리움, 군중, 하늘·도시 배경 |
| 05 디테일 | 흑백 선화 상세 단면: 레이어 해치, FFL/FSL/USL, 구성 주석, 가로 맥락 |

## 핵심 결정
1. **형태는 코드, 마감은 AI.**
   코드로 그린 SVG는 구도·선 언어·정확한 치수까지 책임진다. 손으로 마감한 보드 수준의 질감과 밀도는 코드로 닿지 않으므로, 이미지 AI가 마지막 단계를 맡는다.
2. **AI에는 항상 두 가지를 같이 보낸다.**
   ① 현재 도면 PNG(형태 고정) ② 사용자가 올린 레퍼런스 이미지(스타일). 레퍼런스가 없으면 탭별 기본 스타일 문장을 쓴다.
3. **형태를 바꾸는 AI 결과는 실패로 본다.**
   지시문은 층·창·벽 위치를 바꾸지 말 것, 가짜 글자를 만들지 말 것을 항상 포함한다.
4. **사용자 키는 사용자 브라우저에만.**
   API 키는 서버를 거치지 않고, 선택한 AI 회사(Google/OpenAI)로만 전송된다. 저장은 선택 사항.
5. **도면은 결정론적이다.**
   같은 입력이면 같은 도면이 나온다(시드 고정 난수). 변주는 '수목 변주', '재질 변주' 숫자로만 바꾼다.

## 구조
| 파일 | 역할 |
|---|---|
| `index.html` | UI, 입력 폼, 기본 도면 함수, 프롬프트 조합, PNG/SVG 저장 |
| `studio.js` | 발표용 도면 엔진. 다섯 렌더러를 교체 (`drawMass`, `drawPlan`, `drawElev`, `drawSection`, `drawDetail`) |
| `render-ai.js` | AI 렌더 패널. Gemini `generateContent` / OpenAI `images/edits` 호출 |

## 하지 않는 것
- 실시공용 도면, 법규·구조 검토 (평면 배치는 면적 비율 개략안, U값은 참고치)
- 서버·로그인·사용자 데이터 저장
- 특정 실존 건축물이나 사무소 작품의 복제

## 성공 판단
레퍼런스 이미지 옆에 AI 렌더 결과를 놓았을 때, **형태는 입력값 그대로이고 그래픽 톤은 레퍼런스와 구분하기 어려우면** 성공이다.
